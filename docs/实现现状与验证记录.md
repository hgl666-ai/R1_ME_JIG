1.1 板上还有一颗 U3（STM32F103RCT6）—— 用作交叉校验
    U3 的模拟前端与 U2 **完全同构**，而且两路缓冲来自**同一个输入节点**：

        MRE-ADC ──┬─ U7A 跟随 ──> U2_MRE  ── U2 PA0 (ADC1_IN0)
                  └─ U7B 跟随 ──> U3_MRE  ── U3 PA0 (ADC1_IN0)

        TBS-S   ──┬─ U6A 跟随 ──> U2_TBS  ── U2 PA1 (ADC1_IN1)
                  └─ U6B 跟随 ──> U3_TBS  ── U3 PA1 (ADC1_IN1)

        3V3_ADC0 ─┬─ U5A 跟随 ──> U2_ADC0 ── U2 PA4 (ADC1_IN4)
                  └─ U5B 跟随 ──> U3_ADC0 ── U3 PA4 (ADC1_IN4)

    结论：U2 和 U3 拿到的是**同一个信号的两份独立缓冲副本**，不是两个不同的
    物理量。所以双片比对能做的是"两条测量链路的一致性检查"（交叉校验），
    不能提高对信号本身的认知。这与 M1 治具的 U1(主控)+U2(副控) 架构同构，
    M1 协议里的"交叉校验块 / U2 无应答"标志位就是干这个的。

    两片之间的连接只有两条：
        UART1  —— H3 排针把 U2_USART1 与 U3_USART1 交叉相连（TX↔RX）
        网络 S —— U2_PC4 ↔ U3_PA2（板载对射传感器的数字输出，R18 1kΩ 上拉到 3.3V）

    U3 没有：USB、TMC2209、电机输出。所以它不能独立与 PC 通信，也不能驱动
    电机，只能做 U2 的从机。

    ★ 2026-11-11 已实现交叉校验（见 1.2）。U3 现在跑一个精简固件：只做 ADC
    连续采样 + 链路应答，没有电机、TMC、USB。

1.2 U3 交叉校验的实现（2026-11-11）
    PC 侧命令   : 0x0021 CROSS_CHECK（见 INFO/命令.md 第一章 1.7）
    内部链路    : USART1 @115200，帧格式与 PC 链路完全相同（复用 protocol_frame.c）
                  命令码 0x0101 PING / 0x0102 GET_SNAP
    线上契约    : U2/Core/Inc/link_proto.h + link_proto.c
                  U3/Core/Inc/link_proto.h + link_proto.c
                  两处必须是**完全相同的副本**；test_host/run.ps1 每次都会做
                  SHA256 比对，不一致直接报错中止。
    判据        : |mre_last 差| > 50 LSB 或 |vref_last 差| > 20 LSB → 判超差
                  （阈值在 U2/Core/Inc/protocol.h 的 PROTO_CROSS_TOL_* 里）

    U2 侧新文件 : Core/Src/link_proto.c、link_u3.c
    U3 侧新文件 : Core/Src/bsp_adc.c、protocol_frame.c、link_proto.c、link_slave.c
                  （bsp_adc.c 与 protocol_frame.c 与 U2 是同一份源码）

    ★ H3 排针必须插 1-2、3-4 两个短接帽，否则 U2 与 U3 的 TX/RX 不相通。
      没插时 0x0021 会回 0C ERR_TIMEOUT，其余命令不受影响。

    资源占用    : U2  Code 21132B / RW 420 / ZI 11084
                  U3  Code  8146B / RW  24 / ZI  5704

2.4 没有 DUT 时如何验证 MRE 模拟前端
    目标：在接被测板之前，先把 U7 跟随器的线性区和上限摸清楚。
    器材：一个 10kΩ 电位器。两端接 CN3 的 3.3V 与 GND，中间抽头接 CN4 pin1。
    （CN3 是 2 位端子，pin2 = 3.3V、pin1 = 信号；用万用表确认哪根是 3.3V。）

    步骤：慢慢旋电位器，每旋一小格发一次 MRE_QUERY（A5 5B 00 20 00 01 00 00 8E B0），
          同时用万用表量 CN4 pin1 对 GND 的实际电压，填表：

        +----------------+--------------+---------------+------------------+
        | CN4 pin1 实测  | 理论 raw     | 实际 mre_last | 差值             |
        +----------------+--------------+---------------+------------------+
        | 0.00 V         | ~0           |               |                  |
        | 0.50 V         | ~620         |               |                  |
        | 1.00 V         | ~1241        |               |                  |
        | 1.50 V         | ~1861        |               |                  |
        | 1.65 V         | ~2047        |               |                  |
        | 1.80 V         | ~2233        |               |                  |
        | 2.00 V         | ~2481        |               |                  |
        | 2.50 V         | ~3102        |               |                  |
        | 3.00 V         | ~3723        |               |                  |
        | 3.30 V         | ~4095        |               |                  |
        +----------------+--------------+---------------+------------------+
        raw 与 mV 的换算：raw = V × 4095 / 3.3

    判读：
      - 全程都能跟随（差值 <10 LSB）→ LM358 在这里够用，接线和运放都没问题，
        直接等 DUT 即可
      - 到某个电压之后 mre_last 不再上升（走平）→ 那个点就是削顶起点，
        记下它。若低于 DUT 的 MRE 输出上限，就必须换轨到轨运放
        （MCP6001 / TLV9061 / OPA340，3.3V 供电可 0~3.3V 跟随）
      - 全程读数都在 2600 附近不动 → 运放没在工作，查 U7 供电和焊接

    注意：CN4 pin1 上并了 D8 SMF3.3A TVS，输入别超过 3.3V；电位器两端接 3.3V/GND
          是安全的。
